# Final Review Prompt

Faça uma revisão independente do projeto inteiro.

1. Compare implementação com `docs/DEFINITION_OF_DONE.md`.
2. Execute todos os testes possíveis.
3. Faça smoke test do fluxo novo jogo -> personagem -> nave -> mapa -> missão -> recompensa -> save -> reload -> painel dos pais.
4. Teste em modo offline.
5. Liste bugs por severidade.
6. Corrija Critical e High antes de finalizar.
7. Corrija Medium quando seguro e dentro do escopo.
8. Revise legibilidade, alvos de toque, animações e feedback para 4 anos.
9. Revise persistência e recuperação de save.
10. Revise conteúdo educacional e segurança infantil.
11. Atualize documentação final.
12. Só então marque PROJECT_STATUS como FINALIZED.
