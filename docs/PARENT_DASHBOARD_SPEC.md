# Parent Dashboard

Protegido por gesto, conta simples ou confirmação adulta.

## Mostrar
- tempo jogado hoje
- habilidades praticadas
- evolução recente
- desafios concluídos
- áreas em desenvolvimento
- novas conquistas
- histórico resumido

## Criar desafio do responsável
Permitir selecionar habilidade e dificuldade.
Exemplo: "Mensagem do Papai: Vini, tenho um desafio especial para você!"

Evitar rankings, diagnósticos ou comparações com outras crianças.
