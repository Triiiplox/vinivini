# Arte, lote 2: 100 palavras novas (5 folhas de 20)

**Para que serve:** o Vini já lê palavras inteiras, então a leitura vai subir para sílabas difíceis, frases e textos curtos. Cada palavra precisa de uma figura, porque é com ela que o jogo confere que ele entendeu o que leu.

As palavras foram escolhidas para treinar as sílabas que vêm depois das simples:
- dígrafos (duas letras que fazem um som só): **LH, NH, CH, RR, SS**;
- encontros consonantais: **BR, TR, PL, FL, CL, GR**;
- nasais: **ÃO, AM, EN, IN, ON, UN**.

## Regras (as mesmas do lote 1)
- Use o mesmo gerador e anexe `art_src/vini/vini_character_sheet_v2.png` como referência de estilo.
- 1536×1024, fundo **cinza claro liso**, grade de **5 colunas × 4 linhas**.
- Um objeto por célula, **na ordem da lista**, sem encostar no vizinho e sem texto.
- Mande o PNG original.

Bloco de estilo para colar no começo de cada prompt:
```
Same 3D animated feature-film style and soft lighting as the reference image: rounded, toy-like,

objects, each centered in its own equal cell with lots of empty space around it, no overlap, no text,
plain flat light gray background. Exactly in this order, left to right, top to bottom:
```
