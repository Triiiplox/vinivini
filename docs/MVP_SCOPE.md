# Escopo do MVP (Step 01)

## Persona
**Vini, 4 anos.** Reconhece sílabas simples, gosta de números, espaço e de ser elogiado. Ainda não lê frases
com fluência → toda instrução é narrada e acompanhada de ícones; botões grandes; uma decisão por tela.

**Responsável.** Quer ver progresso sem jargão, criar desafios e controlar som/tempo. Acessa por porta adulta.

## Pilares → onde estão no jogo
| Pilar | Onde |
|---|---|
| Leitura | Lua: Sílabas (3 níveis), Montar Palavra (3 níveis); nome do planeta no Laboratório |
| Matemática | Marte: Contar, Somar (soma concreta), Comparar |
| Lógica | Saturno: Padrões, Memória |
| Histórias / imaginação | Biblioteca/Nebulosa: 2 histórias ramificadas (5 finais); Laboratório de Planetas |
| Emoções e respeito | Nebulosa/Biblioteca: Sentimentos (reconhecer + escolher atitude gentil) |
| Ciência | Observatório: 10 corpos do Sistema Solar com fatos revisados + Quiz |
| Autonomia/persistência | erro não pune, dica após 2 erros, elogio de persistência, Desafio de Comandante |

## Fluxo principal
JOGAR → criar astronauta → intro do Cosmo → **Nave** → Mapa → planeta → Missão (4 rodadas adaptativas) →
elogios e dicas → resultado (estrelas, itens novos, nível novo) → voltar ao planeta/nave → Oficina/Troféus
para usar itens. Pais: segurar cadeado 2s → conta → painel.

## Fora do MVP (ver FUTURE_ROADMAP)
iOS, nuvem/sincronização, múltiplos perfis na UI (a camada de dados já aceita `profile_id`), outros idiomas,
desenho livre, multiplayer, loja/compras (nunca).

## Limites assumidos
- Um perfil infantil por aparelho (nome editável no painel).
- Narração depende da voz pt-BR do sistema; sem ela, o jogo funciona só com texto.
