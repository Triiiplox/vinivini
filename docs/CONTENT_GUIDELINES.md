# Content Guidelines

## Linguagem
Frases curtas, vocabulário claro, instruções narráveis.

## Leitura
Progressão sugerida:
- som/letra
- sílabas simples
- combinação de sílabas
- palavras familiares
- frases curtas
- micro-histórias
- interpretação simples

## Matemática
- quantidade
- reconhecimento numérico
- comparação
- sequência
- soma concreta
- subtração concreta
- padrões
- problemas visuais
- multiplicação intuitiva futura

## Emoções
Nunca tratar uma emoção como moralmente errada. Diferenciar emoção de comportamento.

## Ciência
Curiosidades curtas e factualmente corretas. Não misturar astrologia com astronomia científica como se fossem equivalentes. Se futuramente astrologia for abordada, apresentar como tradição/cultura, não como ciência.
