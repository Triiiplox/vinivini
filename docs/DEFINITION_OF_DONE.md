# Definition of Done

MVP só está pronto quando:
- abre sem internet;
- perfil infantil pode ser criado;
- personagem pode ser customizado;
- nave-hub funciona;
- mapa possui ao menos 3 destinos;
- existem 5 minigames diferentes;
- leitura funciona;
- matemática funciona;
- lógica funciona;
- existe ao menos 1 história ramificada;
- existe ao menos 1 fluxo de emoções/respeito;
- recompensas desbloqueiam itens;
- progresso persiste após fechar e abrir;
- dificuldade adapta em nível básico;
- área dos pais mostra progresso;
- áudio pode ser ligado/desligado;
- interação é adequada a toque;
- não existem crashes conhecidos no happy path;
- smoke test completo passa;
- build Android é gerável.
