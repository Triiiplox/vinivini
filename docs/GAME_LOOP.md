# Game Loop

1. Entrar na nave
2. Receber missão
3. Escolher destino
4. Explorar cenário
5. Encontrar desafio contextual
6. Resolver interação
7. Feedback visual/sonoro
8. Registrar aprendizado
9. Receber recompensa
10. Continuar história ou voltar ao hub

Sessões recomendadas: curtas e concluíveis, aproximadamente 5-10 minutos por missão, sem bloquear jogo livre.
