# STEP 02 — Core Architecture

## Objetivo
Implementar EventBus, services, repositories, models e separação das engines.

## Processo obrigatório
1. Inspecionar estado atual.
2. Implementar.
3. Testar.
4. Corrigir.
5. Fazer revisão de qualidade.
6. Aplicar melhorias de baixo risco e alto valor.
7. Testar novamente.
8. Atualizar PROJECT_STATUS, CHANGELOG e DECISIONS quando necessário.

## Critérios de aceite
- Camadas desacopladas; dependências principais injetáveis/substituíveis; projeto roda.
- Nenhuma regressão crítica introduzida.
- O projeto permanece executável.

## Saída esperada
Marcar como PASS apenas com evidência de teste.
